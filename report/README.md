# Report: Huffman frente a LZW

LaTeX source of the research report (Universidad de Lima, Trabajo de Investigación 2026-2).

## Build

```bash
./build.sh            # from report/; needs ../results (run `ant benchmark` in ../code first)
```

The script sources `../env.sh` (portable Tectonic), copies `../results/*.csv` and
`../results/*.tex` into `report/results/` (plus `../results/replica/fits.csv` as
`results/fits_replica.csv`, the E1 replica shown next to the main fits), and compiles
`build/main.pdf`. Tectonic runs BibTeX
and the reruns automatically.

If a result file is missing, the PDF still builds: the affected figure or table is replaced by a
red "Pendiente" box and missing macros print a red `??`.

## Layout

| Path | Contents |
|---|---|
| `main.tex` | Preamble, member names and colors, title page, front matter, `\input` of each section |
| `sections/01-introduccion.tex` … `07-conclusiones.tex` | One file per report section |
| `sections/08-anexos.tex` | Appendices: reproducibility and individual contributions |
| `refs.bib` | Verified bibliography (IEEE numeric style via `IEEEtran.bst`) |
| `figures/ulima-logo.jpg` | University logo for the title page |
| `results/` | Generated by `build.sh` (do not edit): CSVs, `macros.tex`, `table_corpus.tex` |
| `build/` | Tectonic output (`main.pdf`, logs) |

## Member names and colors

Edit only the block marked `INTEGRANTES Y CÓDIGO DE COLORES` in `main.tex`:
`\integranteA` … `\integranteE` (five members, names still placeholders), `\docente`, and the
colors `memberA` … `memberE`. Ownership: A Huffman, B LZW, C methodology and benchmark harness,
D abstract, introduction, state of the art, conclusions and bibliography, E results analysis
(Section 5), H1 discussion and the theory-vs-experiment comparison (7.1).
Content owned by a member is wrapped in `\begin{aporte}{A}` … `\end{aporte}`, which prints it in
that member's color with a thin left bar. Floats inside an `aporte` must use `[H]`.

## Interpretation and numbers

The interpretation in `05-resultados.tex`, `06-discusion.tex`, `07-conclusiones.tex` and the
abstracts is written against the final results. Numbers come from the `\res*` macros where one
exists; numbers typed in prose were read from the CSVs in `../results/` and must be updated by
hand if the benchmark is rerun.
